# Java File Handling Utility

## 📌 Overview
This project is a simple Java File Handling Utility that demonstrates basic file operations using Java File I/O. It provides a menu-driven console application to write, read, and modify data in a text file.

## ✨ Features
- Write data to a text file
- Read data from a text file
- Append (modify) new data to an existing file
- Menu-driven console interface
- Exception handling using try-catch

## 🛠 Technologies Used
- Java
- FileWriter
- FileReader
- BufferedReader
- Scanner

## 📂 Project Structure
fileHandling.java
notes.txt
README.md

## ▶️ How to Run
1. Clone this repository.
2. Open the project in your Java IDE (VS Code/Eclipse/IntelliJ).
3. Compile the program:
   javac fileHandling.java
4. Run the program:
   java fileHandling

## 📋 Menu Options
1. Write File
2. Read File
3. Modify File
4. Exit
